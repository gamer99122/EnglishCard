# 英文單字卡

左滑答錯、右滑答對的英文短語單字卡。純靜態網頁，沒有後端，答題紀錄存在瀏覽器裡。

網址：https://gamer99122.github.io/EnglishCard/

## 使用方式

1. 第一次打開時按「匯入單字檔」，選擇 `words.json`。
2. 設定範圍（編號從幾號到幾號）和模式，按「開始」。之後打開網頁會用上次的設定直接出卡片。
3. 點卡片翻面看中文，翻面時會自動唸英文。
4. 右滑（或 →）代表答對，左滑（或 ←）代表答錯，下方也有 ✓／✗ 按鈕。

手機建議把網頁「加入主畫面」，避免 iPhone Safari 7 天沒開就清掉網站資料。

### 模式

| 模式 | 出哪些題目 |
|---|---|
| 全部 | 範圍內所有單字 |
| 今日該練 | 範圍內到期要複習的字，加上還沒練過的新字 |
| 只練錯題 | 範圍內還在錯題庫的字 |

### 規則

- **答錯重練**：答錯的卡會排到這一輪最後再考，直到答對為止。只有每個字在這一輪第一次的作答會寫進紀錄。
- **撤銷**：「↶ 撤銷」會退回上一題，那一題的紀錄也會還原。
- **錯題庫**：答錯就加進去，連續答對 2 次才移出。
- **複習排程**：答對後依連續答對次數，排在 1、3、7、14、30、60 天後再出現；答錯就排到明天。

## 單字檔格式

```json
[
  { "id": 1, "en": "a job seeker", "zh": "求職者", "note": "seek v. 尋找" },
  { "id": 2, "en": "an important client", "zh": "重要客戶" }
]
```

- `id`（整數）、`en`、`zh` 必填；`note` 是補充用法，可以省略，用 `\n` 換行。
- 匯入時依 `id` 合併：同 id 會覆蓋，新的 id 會加進去，所以可以每批 Day 各存一個檔案分次匯入。
- 單字內容出自有著作權的書，`words.json` 已寫進 `.gitignore`，不會放進 repo。

## 資料與備份

答題紀錄存在瀏覽器的 localStorage，key 都以 `englishcard.` 開頭。不同瀏覽器、不同裝置的紀錄各自獨立。換裝置或清除瀏覽器資料前，先用「匯出進度」備份，到新的地方再「匯入進度」。

## 開發

- 不用安裝、不用 build：直接雙擊 `index.html` 就能在本機開啟。
- 測試：`node --test`（需要 Node 18 以上）。

| 檔案 | 內容 |
|---|---|
| `index.html` | 畫面和樣式 |
| `app.js` | 畫面操作、滑動手勢、儲存、匯入／匯出 |
| `logic.js` | 錯題庫、複習排程、範圍篩選、匯入檢查等純函式 |
| `logic.test.js` | `logic.js` 的測試 |
